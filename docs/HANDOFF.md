## Gotchas (learned the hard way)
- **Don't run `vite dev` in a sandbox with many worktrees** (file-watcher limit). Use `npx vite build && npx vite preview --port <p> --strictPort`.
- Production builds default to the PUBLIC relay (`wss://wayfarer-relay-production.up.railway.app`). For local multi-client tests: `VITE_SERVER_URL=ws://localhost:2567 npx vite build`, relay: `cd server && PORT=2567 DATA_DIR=/tmp/x node index.js`.
- **Vercel does not upload `server/` or `tools/`** (`.vercelignore`): the client must never import from them (a previous deploy failed that way). Verify by building a copy of the repo without those dirs.
- Phaser has no `keydown-1..9` events; all hotkeys go through `src/core/input.js` (`input.registerAction` / `input.on` / `input.addCloser`). Taken keys: WASD, J, 1-6, Q, E, F, Y, I/B, C, K, L, U, N, M, H/F1, P, O, G, V, T?, Enter, Space, Shift, Tab, X.
- Two-phase asset loading: title appears fast; Creator/World/UI wait for background load (`src/assets/worldLoad.js`, `src/scenes/lazy.js`). After pressing Enter on the title, wait for scene state (`window.__wayfarer.scene.isActive('world')`) in tests, don't use fixed sleeps.
- `/trade` is the server-checked trade window (`src/ui/economyUI.js`); the owner's trust-model gift is `/gift` ("Quick gift" in the player context menu); duels are `/duel`.
- Merging a branch that edits `server/` redeploys the live relay: old clients' saves are refused once a character trades (revision numbers). Ship client + relay together.
- No private keys / seed phrases / secrets in the repo, ever. Wallet code must only sign an off-chain login message.
